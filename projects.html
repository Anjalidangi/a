Driver Drowsiness Detection System

A real-time driver monitoring system designed to detect signs of drowsiness using facial landmarks and a Convolutional Neural Network.

  • Used facial landmarks and Eye Aspect Ratio (EAR) to monitor eye closure.
  • Combined EAR-based detection with CNN predictions for drowsiness classification.
  • Implemented real-time image preprocessing using OpenCV and facial landmark detection using Dlib.
  • Generated an audio alert at approximately 1.5 seconds after detecting prolonged drowsiness.
  • Achieved approximately 92% classification accuracy during model evaluation.
